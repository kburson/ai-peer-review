# ai-peer-review

`ai-peer-review` is the standalone, provider-neutral peer-review protocol
extracted from `kburson/ai-task-manager`.

This repository is not yet released. Its retained history ends at filtered tip
`bfc6f9ffabd8281a815c7bd0e0824f3bacb84d9d`, derived from AITM source commit
`4b3bcd43cba141a611da4a2b861433b915462806`. Ancestors of the first standalone
bootstrap commit retain their historical AGPL-3.0-or-later and commercial terms.
The standalone bootstrap commit and its descendants are Apache-2.0 only under
the independently verified declaration in
`provenance/relicensing-declaration.json`.
