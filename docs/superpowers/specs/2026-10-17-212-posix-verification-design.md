## Concrete implementation decisions

A small CI-only scope resolver is shared by the workflow scope job and native project gate. Its closed scopes are all and linux-macos. Exact #190 source branch always selects linux-macos; other push/PR branches select all; other manual refs may explicitly select linux-macos. Workflow scope job publishes its selected scope in its GitHub job name and output. Matrix and standalone Windows jobs consume that output before scheduling. Receipt verification requires the matching successful scope job and every expected selected worker/lane, and rejects any running/completed Windows job for linux-macos. Native provider uses an honestly named test-cloud-declared-platforms classification and branch-aware project gate; its all mode remains the default on other branches. No generic policy framework.
