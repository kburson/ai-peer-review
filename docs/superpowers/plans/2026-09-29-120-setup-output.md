# Defect 120 Setup Output Implementation Plan

> **For agentic workers:** Use test-driven development for each behavior change. Work in the bound issue worktree and keep commits attributed to `[#120]`.

**Goal:** Make a successful `setup` or `setup --update` unmistakable to a human while preserving the full result for agents that request JSON.

**Architecture:** `src/config/setup.mjs` continues to own setup operations and returns the existing plan/result objects. `src/cli/run.mjs` chooses text or JSON from an explicit setup flag. `src/cli/parse.mjs` and `src/cli/help-data.mjs` document the new output choice.

**Tech Stack:** Node.js ESM, `node:test`, the existing CLI fixture.

**Source:** [Defect #120](https://github.com/kburson/ai-peer-review/issues/120) and its mirrored deep dive.

## Constraints

- Preserve `ai-peer-review.setup-result/v1` and `ai-peer-review.setup-plan/v1` payloads.
- Do not infer output mode from TTY state; `--json` is explicit.
- Report applied/no-changes accurately and label dry-run as a preview.
- Do not touch AITM or publish to npmjs.
