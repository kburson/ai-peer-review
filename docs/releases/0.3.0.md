# ai-peer-review 0.3.0

Version 0.3.0 will require Node.js 24 or later. Dropping Node.js 22 is a
breaking runtime compatibility change. Before 1.0, this project communicates
that break by incrementing the minor version from the 0.2.x line to 0.3.0.

Package verification accepts both supported single-package report formats:
the npm 11 array form and the npm 12 object keyed by package name. The parser
selects by JSON shape rather than the npm version string and rejects malformed,
ambiguous, incorrectly named, or structurally incomplete reports.

Node.js 26 remains the preferred development runtime, while release
verification executes at the supported Node.js 24 floor. Hosted CI runs live
packaging and smoke tests with npm 11.8.0 and npm 12.0.2.

The project-local broker introduces a package-owned native security helper for
retained OS locks and authenticated local IPC. It is not compiled during
installation. Operators explicitly build the helper from a writable source or
installed package with an absolute, local Node development tree matching the
running Node version and architecture:

```bash
npm run build:broker-security -- --nodedir /absolute/local/node-development-tree
npm --prefix ./node_modules/ai-peer-review run build:broker-security -- --nodedir /absolute/local/node-development-tree
```

The exact `node-gyp@12.4.0` production dependency is reachable only through
that command. The builder uses no lifecycle hook or automatic download. Doctor
reports the installation-specific recovery command; without a matching helper,
broker startup fails closed while existing manual review operations remain
available.
